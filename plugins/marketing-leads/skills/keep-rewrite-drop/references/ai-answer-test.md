# The AI-answer test

About ten minutes a page by hand. One question decides it: **what does this page have that the AI answer doesn't?**

## 1. The search

Take the search the page should win: the one with the buying intent the page is there for, closest to a lead. Not simply the search with the most impressions. A definition search can bring impressions to a pricing page; the search that matters for that page is the one a buyer types before asking for a price.

If the page has no search with buying intent at all, say so: that is a finding, and it points to merge or drop.

## 2. The answer

- With a tool that fetches Google results including the AI Overview: use it for that search, in the page's market and language, and quote the answer.
- Without one: ask the person to search it in Google, logged out, and paste the AI answer. Five pages at a time.
- No AI answer for that search: use the top three results instead, and say so.
- AI assistants (ChatGPT, Perplexity, Gemini, Claude) run their own searches before they answer, and pull from pages that rank for them. The Google answer is a good stand-in; you don't need to test every assistant.

## 3. Side by side

Make two short lists:

- **What the answer has that the page misses.** Keep only what a searcher would expect to find. These are gaps to close, briefly.
- **What the page has that the answer lacks.** Only things that count:
  - a number from the company's own data
  - a position someone could disagree with
  - a detail from a real project or customer
  - a tool: a calculator, a checklist, a template
  - first-hand experience: proof the author did the work

  Not: more words, a nicer layout, the same points in a different order, a longer list.

## 4. The decision

| The second list | Buyers care about the topic? | Another page says it? | Decision |
|---|---|---|---|
| Has something | | | **Keep and sharpen.** Move that thing to the top. Link the page to the commercial page it should feed |
| Empty | Yes | No | **Rewrite with a position.** Open with the question buyers ask next, answer it with something only this company has, using the template from group 1 |
| Empty | | Yes | **Merge** into the stronger page and redirect |
| Empty | No | No | **Drop** |

Done when every page in the batch has one of the four decisions, with the reason in one line.
