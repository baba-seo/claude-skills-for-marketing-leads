# Getting the data

Give the person only the steps for the file they are about to export.

## Search Console Performance export

1. Open Search Console and pick the property for the website.
2. Go to **Performance**, then **Search results**.
3. Set the date range to the last 3 months.
4. Click **Export** at the top right, then **Download CSV** (or **Download Excel**).
5. Upload the file here as it is. The CSV download is a zip with one file per table (queries, pages, countries and more); there's no need to unzip it.

Notes to share only if they come up:
- Each table in the export holds at most 1,000 rows, which is plenty for this diagnosis.
- Search Console leaves out rare queries for privacy, so the queries table adds up to less than the site's total clicks.
- If the site has several properties (for example one per country), export the one that brings the most clicks first.

## CRM leads, last quarter

Ask for a list of the leads created in the last full quarter, exported from the CRM's contacts, leads or deals view, with these columns where they exist:

- created date
- source (or "original source", "lead source")
- the answer to "how did you hear about us", if the form or sales asks it
- current stage, and whether it became a deal

Tell them to remove names, emails and phone numbers before uploading; the diagnosis doesn't need them.

With the export: count leads per source, and the share of each source that became a deal. For check 8, put their answers from the last 10 new leads next to what the CRM says for the same leads.

## If they can't export

Work from what they can read on screen: total organic clicks, the top 20 queries, the top 10 pages. Say in the diagnosis that those figures are read off the screen, not from an export.
